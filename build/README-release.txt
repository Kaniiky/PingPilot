PingPilot — free, open-source network & PC optimizer for gamers (Windows 10/11, 64-bit)
=====================================================================================

ENGLISH

1. Run PingPilot.exe. Windows asks for administrator rights (needed for tweaks, DNS and priority).
2. SmartScreen may say "Windows protected your PC": the app is not code-signed.
   Click "More info" > "Run anyway". Compare the zip's SHA-256 with the one on the release page.
3. If the window is blank, install Microsoft Edge WebView2: https://go.microsoft.com/fwlink/p/?LinkId=2124703
4. Nothing changes until you turn it on. Settings > "Undo all" restores every original value.
5. Problem? Settings > "Export logs to send", and attach the .zip to a GitHub issue.

Source code, license (MIT) and credits: see LICENSE.txt, CREDITS.md and the GitHub repository.

PORTUGUÊS

1. Abra o PingPilot.exe. O Windows pede administrador (necessário para ajustes, DNS e prioridade).
2. O SmartScreen pode mostrar "O Windows protegeu o computador": o app não tem assinatura digital.
   Clique em "Mais informações" > "Executar assim mesmo". Compare o SHA-256 do zip com o da página da versão.
3. Se a janela abrir em branco, instale o Microsoft Edge WebView2: https://go.microsoft.com/fwlink/p/?LinkId=2124703
4. Nada muda até você ligar. Configurações > "Desfazer todos" volta tudo aos valores originais.
5. Deu problema? Configurações > "Exportar logs para enviar" e anexe o .zip numa issue do GitHub.
